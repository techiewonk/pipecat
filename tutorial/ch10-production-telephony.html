Everyday production features

🎯 Mostly recombinations

Observability

In production you need to see latency (TTFB), per-service timing, token usage, and health. Observers watch frames read-only; heartbeats confirm liveness; Sentry ships metrics. Docs: Metrics.

class MyObserver(BaseObserver):
    async def on_push_frame(self, data):        # called per frame, never blocks the flow
        logger.debug(f"{type(data.frame).__name__}")
# enable timing on the worker:
worker = PipelineWorker(pipeline, params=PipelineParams(enable_metrics=True, enable_usage_metrics=True))

🐍 Python note — observer vs processor

A processor sits in the pipeline and can change frames; an observer sits beside it and only watches. Use observers for logging/metrics so you can't accidentally break the flow.

Telephony — put it on a phone

Several transports connect your agent to a call. Twilio (over a websocket) is the most common; the others suit specific needs.

TransportUse it forSetup note
Twilio (websocket)Classic phone numbers, IVR, outbound/inbound PSTN.Run ngrok http 7860, point a TwiML app at it; -t twilio -x <ngrok-host>.
VonageAlternative PSTN provider (transports-vonage.py).Vonage voice app + webhook URL.
WhatsAppVoice/'messaging over WhatsApp Business.WhatsApp Business API credentials.
DailyWebRTC rooms + dial-in/out; simplest managed path.DAILY_API_KEY; -t daily.
LiveKitSelf-hostable WebRTC/SIP at scale.LiveKit server + keys.

DTMF keypad menus (Chapter 2) pair with these for "press 1 for…" flows.

▶️ Run it

uv run python features/features-wake-phrase.py       # bot ignores you until the wake word
uv run python features/features-live-translation.py  # speak one language, hear another
uv run python observability/observability-observer.py
# phone: ngrok http 7860 ; then  uv run python getting-started/06-voice-agent.py -t twilio -x <host>

🔨 Modify it

Change the wake phrase to 2–3 clear words. Add enable_metrics=True and read the TTFB output. Wire a DTMF menu (features-dtmf-menu.py) onto a Twilio call.

⚠️ Common errors

Wake phrase never triggers → too long/uncommon for STT. DTMF does nothing → needs a phone transport. Nothing logged → observer not registered. Twilio silent → ngrok host wrong or TwiML app misconfigured.

✅ Checkpoint

Why prefer an observer over a processor for logging, and what's the default phone path?

An observer can't alter or stall the frame flow. Twilio-over-websocket (with ngrok) is the most common phone path; Daily is the simplest managed one.
