Feature-based tutorial

Pipecat, by feature — from first sound to an all-in-one Gemini Live A2A

A hands-on, production-minded course. Each capability is explained exactly once — no repetition — and every chapter builds toward one goal: a multi-agent Gemini Live agent-to-agent (A2A) system that runs both locally and distributed.

🎯 How this course is organized

We teach features, not files. There are 380 example scripts in the repo; most are the same pattern with a different provider. So instead of walking all of them, each chapter takes one feature, explains it once, shows annotated real code, and lists which example files demonstrate it. Common building blocks (pipeline, frames, workers, the bus) are defined in Chapter 0 and referenced everywhere else.

▶️ Before you begin

From the repo root: uv sync --all-extras, then cp env.example .env and add keys for the providers you'll use (for the capstone you mainly need GOOGLE_API_KEY). Run any example with uv run python <path>.py and open http://localhost:7860/client/.

📥 Works offline

This tutorial has no internet dependencies — the theme, navigation, and syntax highlighting are all local. The chapters read fully offline right now. To also mirror the 344 linked documentation pages (the full API Reference plus every chapter's "Docs" link) for offline reading, run this once with internet:

python tutorial/build_offline_docs.py   # or: uv run python tutorial/build_offline_docs.py

It saves themed local copies under tutorial/reference/ and rewrites every doc link in every page to point at them. After that, nothing here needs a connection.
