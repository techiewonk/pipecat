Floe LLM

LLM service that routes OpenAI-compatible chat completions through Floe with per-call spend caps

Overview

FloeLLMService provides an OpenAI-compatible interface for running LLMs through Floe — a unified billing ledger for voice AI where one key powers the LLM, STT, and TTS legs of an agent, metered per call and bounded by pre-call spend caps. It extends Pipecat's OpenAILLMService, so streaming responses, function calling, usage/TTFB metrics, and OpenTelemetry tracing all work unchanged.

Installation

This is a community-maintained package distributed separately from pipecat-ai:

uv add pipecat-floe

Prerequisites

Floe Account Setup

Before using the Floe LLM service, you need:

  1. Floe Account: Sign up at the Floe dashboard
  2. API Key: Create an agent key from your dashboard. New keys come with

welcome credit that covers the first calls.

Required Environment Variables

  • FLOE_API_KEY: Your Floe agent key for authentication

Configuration

<ParamField path="api_key" type="str" default="None"> Floe agent key. Falls back to the FLOE_API_KEY environment variable if not provided. Raises ValueError if neither is set. </ParamField>

<ParamField path="model" type="str" default="openai/gpt-4o-mini"> Fully qualified provider/model identifier (for example "openai/gpt-4o-mini" or "anthropic/claude-sonnet-4-6"). A bare model name is rejected by Floe. </ParamField>

<ParamField path="base_url" type="str" default="https://credit-api.floelabs.xyz/v1"> Floe OpenAI-compatible base URL. </ParamField>

<ParamField path="task_id" type="str" default="None"> Optional Floe task ID sent as the X-Floe-Task-Id header on every request, so a per-task budget can bound one conversation. </ParamField>

<ParamField path="kwargs"> Additional keyword arguments passed through to the underlying OpenAILLMService. </ParamField>

Usage

from pipecat_floe import FloeLLMService, FloeSTTService, FloeTTSService
from pipecat.pipeline.pipeline import Pipeline

# One Floe key powers all three legs, on a single budget.
stt = FloeSTTService()                              # streaming STT (WebSocket)
llm = FloeLLMService(model="openai/gpt-4o-mini")    # OpenAI-compatible
tts = FloeTTSService(model="openai/tts-1", voice="alloy")

# Build pipeline
pipeline = Pipeline([stt, llm, tts])

See the source repository for a complete runnable example wiring a WebSocket transport → STT → LLM → TTS.

Compatibility

Built and verified against Pipecat v1.7.0+. Check the source repository for the latest tested version and changelog.
