Lesson 9 · Part II — The voice loop

Context & aggregators

⏱ 40 minLevel: intermediate

The LLM has no memory of its own. The context is the conversation, and the aggregators are the hub that fills it — and where turn-taking and muting attach next lesson.

The context is the memory

An LLMContext is a list of messages (system/developer, user, assistant). Because LLMs are stateless, Pipecat resends the whole context each turn — the aggregators keep it current automatically.

The aggregator pair

from pipecat.processors.aggregators.llm_context import LLMContext
from pipecat.processors.aggregators.llm_response_universal import (
    LLMContextAggregatorPair, LLMUserAggregatorParams)
from pipecat.audio.vad.silero import SileroVADAnalyzer

context = LLMContext()                                  # optionally LLMContext(tools=[...])
user_agg, assistant_agg = LLMContextAggregatorPair(
    context,
    user_params=LLMUserAggregatorParams(vad_analyzer=SileroVADAnalyzer()),
).pair()

pipeline = Pipeline([
    transport.input(), stt,
    user_agg,                     # ← user turn goes IN here
    llm,
    tts, transport.output(),
    assistant_agg,               # ← bot turn recorded here (after output)
])

🐍 Why the assistant aggregator sits after transport.output()

So the bot's words are recorded into context only once they've actually been sent — keeping memory faithful to what the user really heard, even across interruptions.

Kicking off a turn

context.add_message({"role": "developer", "content": "Please introduce yourself."})
await worker.queue_frames([LLMRunFrame()])              # trigger a response now

An LLMRunFrame tells the LLM to respond to the current context — that's how you make the bot speak first on connect.

The aggregator family

Beyond the pair, processors/aggregators/ holds specialized aggregators you'll meet later: sentence.py (sentence assembly), dtmf_aggregator.py (keypad), gated.py/gated_llm_context.py (hold frames until a condition), llm_context_summarizer.py (Lesson 21), llm_text_processor.py (Lesson 13), and async_tool_messages.py (Lesson 12).

✅ Checkpoint

1. Why must Pipecat resend the whole context every turn?

LLMs are stateless — they don't remember prior turns, so the full conversation is resent each time.

2. What do the two aggregators do?

The user aggregator records your turn into the context; the assistant aggregator records the bot's reply after it's sent.
