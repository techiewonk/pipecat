The complete course

Pipecat, 0 to Hero

A single, source-grounded path from "never heard of Pipecat" to "can design and ship a distributed multi-agent voice system." Every lesson explains the real classes that implement the idea, then hands you an annotated program you can run.

🎯 How this course works

Two code tracks per lesson: a self-contained mini-example to learn the idea in isolation, and one step of the "Atlas" capstone — a single project that grows lesson by lesson from a say-one-thing bot into a Gemini Live agent-to-agent system running locally and distributed. Each lesson follows the same rhythm: 🎯 objective · 🧠 principle · 🔬 source anchors · 💻 runnable code · 🏋 exercise · ✅ checkpoint.

✅ Full-coverage guarantee

This course is audited so that every one of the 24 src/pipecat packages and every official Fundamentals + Evals doc maps to a lesson — see the Coverage matrix. Nothing in the framework is left out.
