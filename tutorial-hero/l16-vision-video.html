Lesson 16 · Part III — Realtime & multimodal

Vision, video & avatars

⏱ 40 minLevel: intermediate

Video frames flow through the pipeline exactly like audio. That one idea unlocks three features: seeing (vision), transforming video, and giving the bot a face.

Frames carry any media

A vision model is just an LLMService that accepts image frames. Video processing transforms the track itself with no LLM. Avatars are a video service/transport that renders a talking head from the bot's speech.

Vision

from pipecat.frames.frames import UserImageRequestFrame
# enable video on the transport, use a multimodal LLM (OpenAI/Anthropic/Gemini),
# then request the current frame when the user asks about what they're showing:
await worker.queue_frame(UserImageRequestFrame(user_id))   # attaches the frame to context
# the vision-capable LLM answers using the image

Start with vision/vision-openai.py; vision-moondream.py runs a small local vision model.

Video processing (no AI)

Pure frame work — mirror, filter, swap tracks, or feed GStreamer sources. These processors live in processors/gstreamer/ and the video-processing/ examples. No model required.

Avatars (talking heads)

Tavus, HeyGen, Simli, and LemonSlice render a face driven by the bot's TTS, wired either as a transport (the avatar owns the room) or a video service (frames added to your pipeline).

uv run python vision/vision-openai.py                       # "what am I holding?"
uv run python video-processing/video-processing-mirror.py   # track transform, no AI
uv run python video-avatar/video-avatar-tavus-transport.py  # a face (needs a Tavus key)

🔬 Source anchors

Vision services under services/* (e.g. moondream) + multimodal LLMs. processors/gstreamer/* for video processing. transports/{tavus,heygen,simli,lemonslice}/ for avatars. Frames: ImageRawFrame/InputImageRawFrame/UserImageRawFrame/OutputImageRawFrame in frames/frames.py.

✅ Checkpoint

1. How do vision/ and video-processing/ differ?

Vision sends frames to an LLM for understanding; video-processing transforms the track itself, usually with no LLM.

2. Two ways to wire an avatar?

As a transport (it owns the room) or as a video service (frames added to your pipeline).
