Lesson 11 · Part II — The voice loop

LLM inference, adapters & settings

⏱ 45 minLevel: intermediate

The LLM is the brain: it reads the context and streams a reply. Swapping providers is a one-line change, and the Settings pattern you learn here powers every runtime config change in Pipecat.

Context in, tokens out

The LLM pushes LLMFullResponseStartFrame, a stream of LLMTextFrames, then LLMFullResponseEndFrame. Streaming is what lets TTS start speaking before the whole answer is generated.

Adapters make providers interchangeable

Each provider expresses tools and messages differently. A BaseLLMAdapter translates Pipecat's LLMContext/tools into the provider format, so most "OpenAI-compatible" services are thin subclasses of BaseOpenAILLMService.

from pipecat.services.openai.llm import OpenAILLMService

llm = OpenAILLMService(
    api_key=os.environ["OPENAI_API_KEY"],
    settings=OpenAILLMService.Settings(
        model="gpt-4.1",
        system_instruction="You are a helpful, brief voice assistant.",
        temperature=0.7,
    ),
)
# OpenAI-compatible provider via base_url — same class:
# llm = OpenAILLMService(api_key=..., base_url="https://api.other.com/v1")
# or a different family entirely:
# from pipecat.services.anthropic.llm import AnthropicLLMService
# llm = AnthropicLLMService(api_key=...)

The Settings pattern (learn once, reuse everywhere)

🧠 Store vs. delta

A service's Settings dataclass is used two ways: a complete store (every field set; None = unsupported) and a sparse delta (only changed fields; unset = the NOT_GIVEN sentinel) carried by an *UpdateSettingsFrame. This is how every runtime change works — STT language, TTS voice, LLM temperature.

from pipecat.frames.frames import LLMUpdateSettingsFrame
# change temperature mid-conversation, no restart:
await llm.queue_frame(LLMUpdateSettingsFrame({"temperature": 0.2}))

✅ Checkpoint

1. What lets TTS start speaking before the LLM finishes?

Token streaming — the LLM emits LLMTextFrames as it generates, which TTS aggregates into sentences and speaks.

2. How do you change a model setting without restarting?

Push an LLMUpdateSettingsFrame (a sparse delta using the Settings pattern).

3. Why are most LLM providers so little code?

They subclass BaseOpenAILLMService and reuse its streaming engine + adapter; they mostly set defaults.
