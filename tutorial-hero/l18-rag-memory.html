RAG & memory

⏱ 35 minLevel: intermediate

LLMs don't know your private documents and will confidently make things up. Retrieval-Augmented Generation fetches relevant text and drops it into the context — and long-term memory persists facts across sessions.

Retrieve, then answer

🧠 RAG is smart context-building

There's no new pipeline magic — RAG is "fetch relevant text, add it to the messages list before calling the LLM." It builds directly on the context (Lesson 9).

The shape
