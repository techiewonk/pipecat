Provider matrix

What you subclass and the (usually one) method you override to add or swap a provider. Source: services/.

Adding a provider

KindSubclassOverride
LLM (OpenAI-compatible)BaseOpenAILLMServiceJust set Settings + defaults (reuses the streaming engine).
LLM (other)LLMService / WebsocketLLMServiceSet adapter_class; implement completion in process_frame/_process_context.
STT (streaming)STTServicerun_stt(audio) (+ optional _connect/_disconnect).
STT (batch/HTTP)SegmentedSTTServicerun_stt(audio) — called once per VAD segment.
TTS (streaming)WebsocketTTSServicerun_tts(text, ctx) + a receive loop emitting TTSAudioRawFrame.
TTS (HTTP)TTSServicerun_tts(text, ctx).
Realtime (speech-to-speech)WebsocketLLMServiceConsume InputAudioRawFrame, emit TTSAudioRawFrame; a long-lived session loop.
Vision / ImageVisionService / ImageGenServicerun_vision(frame) / run_image_gen(prompt).

Every provider defines a Settings dataclass (extending the modality's), exposes it as Settings = …, and implements can_generate_metrics() / language_to_service_language() where relevant.
