The one picture: a voice turn

Everything in Pipecat is a frame (a typed packet of data) moving through a pipeline (an ordered list of processors). Watch a single spoken turn travel through the loop — the packet is a frame, and it changes form at each stage:

The glowing wave is a frame flowing left-to-right; the caption tells you what it has become. Hit pause to study a stage.

Get ready to run things

▶️ One-time setup

# from the repo root
uv sync --all-extras          # install Pipecat + every provider extra
cp env.example .env           # then add API keys for the providers you'll use
uv run python getting-started/01-say-one-thing.py
# open http://localhost:7860/client/ and click Connect

For most of the course you only need a few keys. The capstone leans on GOOGLE_API_KEY (Gemini Live); early voice lessons use DEEPGRAM_API_KEY (STT) and CARTESIA_API_KEY (TTS), and any one LLM key (e.g. OPENAI_API_KEY).

✅ Checkpoint

1. In the animation, what actually "flows" through the pipeline?

A frame — a typed data packet. It changes type at each stage (audio → text → context → reply text → audio).

2. What is the difference between the mini-examples and "Atlas"?

Mini-examples teach one idea in isolation; Atlas is a single project you keep extending until it becomes the distributed Gemini Live A2A.
