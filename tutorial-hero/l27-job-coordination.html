Lesson 27 · Part V — Multi-agent

Job coordination

⏱ 45 minLevel: advanced

Where handoff moves control to one agent, job coordination dispatches work to several agents in parallel and collects their results — the "consult the committee" pattern.

Fan out, then synthesize

Dispatching a job group

from pipecat.workers.llm.llm_context_worker import LLMContextWorker
from pipecat.workers.llm.tool_decorator import tool

class Coordinator(LLMContextWorker):
    @tool
    async def consult(self, params, topic: str):
        """Ask several specialists at once and combine their views."""
        async with params.pipeline_worker.job_group(
            DebateWorker("advocate"), DebateWorker("critic"), DebateWorker("analyst"),
        ) as group:
            results = await group.run(topic)          # waits for all peers
        await params.result_callback({"perspectives": results})

# each peer handles the job:
class DebateWorker(LLMContextWorker):
    async def on_job_request(self, message):
        answer = await self.run_inference(message.payload)
        await self.send_job_response(message, answer)

🐍 async with … as group

The job group is an async context manager: it sets up the peers, guarantees cleanup, and await group.run(...) gathers every peer's result before continuing. A single peer uses job(worker_name); groups can also stream progress and be cancelled.

✅ Checkpoint

1. Handoff vs. job coordination — the difference?

Handoff moves control to one agent; job coordination dispatches to several in parallel and collects all results.

2. What does await group.run(...) guarantee?

It gathers every peer's result before the coordinator continues (or times out).
