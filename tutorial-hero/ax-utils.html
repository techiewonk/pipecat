utils/ reference

The helper library (src/pipecat/utils/, ~50 files) — small utilities the framework leans on. You rarely import these directly, but knowing they exist saves you from reinventing them.

🧭 How to explore

Browse src/pipecat/utils/ directly, or search the codebase for an import you see in a lesson (e.g. from pipecat.utils.text.markdown_text_filter import MarkdownTextFilter) to find the helper and its neighbors.
