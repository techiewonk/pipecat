UIWorker + RTVI client

⏱ 45 minLevel: advanced

RTVI is the protocol your browser/mobile client speaks to a bot. A UIWorker bridges the bus to that client so voice can see and drive a web GUI — read the screen, fill forms, show progress.

RTVI: the client protocol

RTVI (Real-Time Voice Inference) is transport messages carrying typed events. An RTVIObserver emits them; an RTVIProcessor handles inbound client messages (client-ready, DTMF, send-text, UI events).

The UIWorker

from pipecat.workers.ui.ui_worker import UIWorker
from pipecat.workers.ui.ui_event_decorator import ui_event

class FormFiller(UIWorker):
    @ui_event("field_focused")
    async def on_field(self, data):
        await self.send_command(scroll_to(data.node_id))     # drive the page

    @tool
    async def fill(self, params, field: str, value: str):
        """Fill a form field for the user."""
        await self.set_input_value(field, value)
        await params.result_callback({"ok": True})
