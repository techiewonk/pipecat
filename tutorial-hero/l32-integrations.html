Lesson 32 · Part VI — Production & quality

Framework integrations

⏱ 25 minLevel: intermediate

Already have an agent built in LangChain or AWS Strands? Drop it into a Pipecat pipeline as a processor and give it a real-time voice.

Your agent, as a processor

These integrations live in processors/frameworks/. Because they're just FrameProcessors, they slot into the pipeline between the context and TTS like any LLM.

LangChain & Strands

from pipecat.processors.frameworks.langchain import LangchainProcessor
chain_proc = LangchainProcessor(chain=my_langchain_runnable)
pipeline = Pipeline([transport.input(), stt, user_agg, chain_proc, tts, transport.output(), assistant_agg])

# AWS Strands Agents:
from pipecat.processors.frameworks.strands_agents import StrandsAgentsProcessor
# see examples/voice/voice-aws-strands.py

processors/frameworks/langchain.py and processors/frameworks/strands_agents.py. Example: examples/voice/voice-aws-strands.py. (RTVI, also under processors/frameworks/, is covered in Lesson 29.)
