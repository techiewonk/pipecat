Lesson 7 · Part II — The voice loop

Audio: filters, resamplers, VAD

⏱ 45 minLevel: intermediateProduction-critical

Real calls are noisy and run at odd sample rates. This is the production-audio layer: clean the mic, convert rates, and detect speech.

The input audio chain

Noise cancellation (audio_in_filter)

Attach a filter to the transport to clean incoming audio before VAD/STT — a big quality win on real calls.

from pipecat.audio.filters.rnnoise_filter import RNNoiseFilter   # free / open
# from pipecat.audio.filters.krisp_viva_filter import KrispVivaFilter  # paid SDK

"webrtc": lambda: TransportParams(
    audio_in_enabled=True, audio_out_enabled=True,
    audio_in_filter=RNNoiseFilter(),                 # clean the mic first
)

Resamplers (the "sampler")

Phone audio is 8 kHz; models want 16/24 kHz. A resampler converts between them so nothing sounds chipmunked. Usually automatic (the output MediaSender uses a streaming one), but you can pick the engine:

from pipecat.audio.resamplers.soxr_resampler import SOXRAudioResampler
resampler = SOXRAudioResampler()          # high quality (SoX)
# SOXRStreamAudioResampler — streaming/realtime · ResampyResampler — pure-Python fallback

VAD: the speech signal

Voice Activity Detection answers "speech or silence?" — the fastest end-of-turn signal. The default is Silero (local, free). You can tune it and place it explicitly, or (more commonly) hand it to the aggregator in Lesson 10.

from pipecat.audio.vad.silero import SileroVADAnalyzer
from pipecat.audio.vad.vad_analyzer import VADParams

vad = SileroVADAnalyzer(params=VADParams(
    confidence=0.7,    # how sure before "speech"
    start_secs=0.2,    # speech must persist this long to start a turn
    stop_secs=0.8,     # silence this long ends the turn
    min_volume=0.6,
))
# explicit placement (standalone route):
from pipecat.processors.audio.vad_processor import VADProcessor
pipeline = Pipeline([transport.input(), VADProcessor(vad_analyzer=vad), stt, ...])

VAD state machine: QUIET → STARTING → SPEAKING → STOPPING. It emits VADUserStartedSpeakingFrame/VADUserStoppedSpeakingFrame that the turn logic consumes.

✅ Checkpoint

1. Which noise filter needs no license?

RNNoiseFilter — the others (Krisp, Koala, ai-coustics) need keys.

2. What does a resampler fix, and where does one usually run automatically?

Sample-rate mismatches (e.g. 8 kHz phone ↔ 24 kHz TTS); the output MediaSender runs a streaming resampler for you.

3. What are the four VAD states?

QUIET, STARTING, SPEAKING, STOPPING.
