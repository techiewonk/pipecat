Lesson 17 · Part III — Realtime & multimodal

Thinking / reasoning

⏱ 25 minLevel: intermediate

Reasoning models spend hidden tokens thinking before they answer, improving hard questions. Pipecat surfaces that as its own frames so you can show, log, or suppress it.

Think, then speak

Thought frames are separate from the spoken answer, so by default the reasoning is not read aloud — but you can log it, show it in a UI, or gate on it.

Enabling thinking

from pipecat.services.anthropic.llm import AnthropicLLMService

llm = AnthropicLLMService(api_key=os.environ["ANTHROPIC_API_KEY"],
    settings=AnthropicLLMService.Settings(
        enable_thinking=True,
        thinking_budget_tokens=1024,   # cap reasoning so latency stays bounded
    ))

🐍 Booleans & budgets

enable_thinking=True turns it on; the budget caps how many hidden tokens the model may spend — the knob that trades quality for latency/cost. Thinking works with function calling too (thinking-functions-* examples).

🔬 Source anchors

frames/frames.py — LLMThoughtStartFrame (561), LLMThoughtTextFrame (589), LLMThoughtEndFrame (613). Providers: Anthropic, Google (+ Vertex), OpenAI Responses. Examples: the thinking/ folder (thinking-anthropic.py, thinking-functions-anthropic.py).

🔨 Exercise

(1) Run thinking/thinking-anthropic.py with a multi-step puzzle. (2) Lower the budget and watch quality vs. speed trade off. (3) Add a processor that logs LLMThoughtTextFrames so you can see the reasoning.

✅ Checkpoint

1. What does a thinking budget control?

How many hidden reasoning tokens the model may use before answering — the quality/latency knob.

2. Are thought frames spoken by default?

No — they're separate from LLMTextFrames, so the reasoning isn't read aloud unless you route it somewhere.
