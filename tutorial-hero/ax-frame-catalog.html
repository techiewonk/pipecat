Appendix A · Reference

Frame catalog

The 125 frame types grouped by lane and role. You don't memorize these — you recognize the families and look up specifics. Source: frames/frames.py.

System lane (high priority)

SystemFrame — preempts buffered data; used for lifecycle, control, input, and speaking events.

FrameMeaning
StartFrame / CancelFrameInitialize / abort the pipeline.
ErrorFrame / FatalErrorFrameRecoverable / fatal error.
InterruptionFrameUser interrupted — cancel in-flight output.
InputAudioRawFrame / UserAudioRawFrameIncoming mic audio.
InputImageRawFrame / UserImageRawFrameIncoming video/image.
InputTextRawFrameText input from the client.
UserStartedSpeakingFrame / UserStoppedSpeakingFrameTurn boundaries.
VADUserStartedSpeakingFrame / VADUserStoppedSpeakingFrameVAD-level speech edges.
UserSpeakingFrame / UserMuteStartedFrame / UserMuteStoppedFrameSpeaking / mute state.
BotStartedSpeakingFrame / BotStoppedSpeakingFrame / BotSpeakingFrameBot speaking state (for UI).
FunctionCallsStartedFrame / FunctionCallCancelFrameTool-call lifecycle.
MetricsFrameTTFB / processing / usage metrics.
STTMuteFrameMute the STT input.
InputDTMFFrame / OutputDTMFUrgentFrameKeypad tones.
SpeechControlParamsFrameBroadcast turn/VAD params.
ServiceMetadataFrame / STTMetadataFrame / LLMServiceMetadataFrameService self-description (e.g. realtime, latency).
UserImageRequestFrameAsk the transport for the current frame (upstream).

Data lane (ordered)

DataFrame — the payloads that flow in order.

FrameMeaning
OutputAudioRawFrame / TTSAudioRawFrameAudio for playback.
OutputImageRawFrame / URLImageRawFrame / SpriteFrameImages/video out.
TextFrameGeneric text.
LLMTextFrameA streamed LLM token.
AggregatedTextFrame / TTSTextFrameSentence-aggregated / spoken text.
TranscriptionFrame / InterimTranscriptionFrame / TranslationFrameSTT results.
LLMContextFrameThe conversation sent to the LLM.
LLMRunFrameTrigger an LLM response now.
LLMMessagesAppendFrame / UpdateFrame / TransformFrameModify context messages.
LLMSetToolsFrame / LLMSetToolChoiceFrameConfigure tools at runtime.
LLMConfigureOutputFramee.g. skip_tts for output.
LLMThoughtStartFrame / LLMThoughtTextFrame / LLMThoughtEndFrameReasoning phase (control/data).
FunctionCallResultFrameTool result (also UninterruptibleFrame).
TTSSpeakFrameSpeak text directly (bypass LLM).
*UpdateSettingsFrameRuntime setting deltas (STT/TTS/LLM/Mixer/Filter).

Control lane (ordered)

ControlFrame — ordered boundary/lifecycle markers: EndFrame, TTSStartedFrame/TTSStoppedFrame, LLMFullResponseStartFrame/LLMFullResponseEndFrame, ServiceSwitcherRequestMetadataFrame, mixer/filter control frames.

Media bases & markers

AudioRawFrame, ImageRawFrame, TextFrame carry payloads and combine with a lane base. UninterruptibleFrame opts a frame out of interruption discarding (e.g. FunctionCallResultFrame).
