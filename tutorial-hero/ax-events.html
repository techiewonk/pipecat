Events reference

Every hook you use to react to the pipeline lifecycle. Services, transports, aggregators, workers, and the RTVI processor all expose event handlers you attach with a decorator. This gathers the ones used across the course into one lookup.

How to attach a handler

# Any emitter (transport, service, aggregator, worker, rtvi) exposes .event_handler(name):
@transport.event_handler("on_client_connected")
async def on_client_connected(transport, client):
    await worker.queue_frames([LLMRunFrame()])       # make the bot greet first

@llm.event_handler("on_function_calls_started")
async def _(service, function_calls):
    await tts.queue_frame(TTSSpeakFrame("Let me check on that."))

Transport events

EventFires when
on_client_connectedA user connects — greet, start the conversation. L2
on_client_disconnectedA user leaves — clean up / cancel the worker.

Service events (STT / TTS / LLM)

EventEmitterFires when

on_tts_requestTTSA synthesis request starts (context id + text).
on_function_calls_startedLLMTool calls begin — say a filler line. L12
on_function_calls_cancelledLLMAn interruption cancelled in-flight tools.
on_completion_timeoutLLMA completion timed out — retry/fallback.

Aggregator / turn / mute events

EventFires when
on_user_turn_started / on_user_turn_stoppedThe user's turn begins / ends. L10
on_user_turn_idleThe user has been silent past the idle timeout. L20
on_user_mute_started / on_user_mute_stoppedServer-side muting engaged / released. L10

Worker & pipeline events

EventFires when

@worker_readyA worker signals it's up (discovery). L25
on_pipeline_started / on_pipeline_finished / on_pipeline_errorThe pipeline worker lifecycle. L5

on_audio_dataAudioBufferProcessor emits captured audio to persist. L22

RTVI / UI events

EventFires when

on_ui_messageThe client sent a UI event / snapshot — routed to a UIWorker.
