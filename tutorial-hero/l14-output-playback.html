Inside the MediaSender

Background audio (mixers)

from pipecat.audio.mixers.soundfile_mixer import SoundfileMixer
from pipecat.frames.frames import MixerEnableFrame, MixerUpdateSettingsFrame

"webrtc": lambda: TransportParams(
    audio_out_enabled=True,
    audio_out_mixer=SoundfileMixer(
        sound_files={"office": "assets/office-ambience.mp3"},
        default_sound="office", volume=0.3),
)
# control it live:
await worker.queue_frame(MixerUpdateSettingsFrame({"volume": 0.15}))   # duck under speech
await worker.queue_frame(MixerEnableFrame(False))                     # bed off

DTMF, volume, and recording

On phone calls, DTMF keypad tones are KeypadEntry values; the output transport can play them natively or synthesize the tones. Output loudness is audio/volume.py. To record the conversation, insert an AudioBufferProcessor that taps the stream to disk without changing playback (revisited in Lesson 22).

from pipecat.processors.audio.audio_buffer_processor import AudioBufferProcessor
recorder = AudioBufferProcessor()
pipeline = Pipeline([transport.input(), stt, user_agg, llm, tts, transport.output(),
                     recorder, assistant_agg])   # taps user + bot audio

✅ Checkpoint

1. Which transport param adds a background bed, and how do you duck it?

audio_out_mixer (e.g. SoundfileMixer); duck it with a MixerUpdateSettingsFrame({"volume": …}).

2. How do you record without affecting playback?

Insert an AudioBufferProcessor — it taps the stream to disk and forwards frames unchanged.
