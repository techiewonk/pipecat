IVR & voicemail

⏱ 35 minLevel: intermediate

Outbound phone bots hit two realities: menu systems ("press 1 for sales") and voicemail. Pipecat's extensions/ package handles both.

Navigating IVR menus

from pipecat.extensions.ivr.ivr_navigator import IvrNavigator
# give it the goal; it listens to menus and presses the right keys to reach it
navigator = IvrNavigator(llm=llm, goal="reach a billing representative")
pipeline = Pipeline([transport.input(), stt, navigator, llm, tts, transport.output()])

Detecting voicemail

On outbound calls you need to know: did a human answer, or a machine? A VoicemailDetector classifies the call so you can leave a message or hang up rather than talking to a beep.

from pipecat.extensions.voicemail.voicemail_detector import VoicemailDetector
detector = VoicemailDetector(llm=llm)
# emits an event when it decides "human" vs "voicemail"; branch your logic accordingly

Backchannel — active listening

Long human turns feel awkward if the bot is silent. Backchanneling makes it emit short acknowledgements — "mm-hmm", "right", "I see" — while the user is still speaking, so the caller knows they're being heard. It's a Pipecat extension (the pipecat-backchannel add-on).

# pip install pipecat-backchannel ; then drop the processor into the pipeline
from pipecat_backchannel import BackchannelProcessor
pipeline = Pipeline([transport.input(), stt, BackchannelProcessor(),   # acknowledges while listening
                     user_agg, llm, tts, transport.output(), assistant_agg])

✅ Checkpoint

1. What does an IvrNavigator do?

Interprets spoken phone menus with the LLM and sends the right DTMF keys to reach a goal.

2. Why detect voicemail on outbound calls?

So the bot leaves a message or hangs up instead of "talking" to a machine's greeting.
